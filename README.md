# Portfolio

The source for [justinp.dev](https://justinp.dev/) - my personal portfolio and web CV.

Built with plain HTML, Tailwind CSS v4 through the browser CDN, vanilla JavaScript, and an unreasonable amount of coffee.

## What's inside

- Responsive personal portfolio
- Separate web CV
- Project showcase
- Open Graph and social metadata
- Accessible interactions and reduced-motion support
- Custom favicon and social-sharing image
- A few easter eggs for people who click things they probably shouldn't
- CapRover deployment using PHP 8.3 and Apache

## Run locally

Serve the directory with any static web server, then open `index.html`.

## Deploy

The included `captain-definition` is ready for CapRover. Deploy the repository root directly.

The downloadable personal CV is deliberately not stored in this public repository.
